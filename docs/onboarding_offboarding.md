# Onboarding / Offboarding

Guía consultable del proceso de alta y baja de colaboradores del grupo. Basado en el documento de responsabilidades. Proceso poco frecuente — no está automatizado, ver nota al final.

## Onboarding — BAE

1. Crear el usuario del colaborador nuevo (prácticas o empleado) en Holded, con sus respectivos documentos.
2. Crear una carpeta personal en Drive dentro de la carpeta de RECURSOS HUMANOS, que incluya:
   - Ficha de datos personales.
   - Copia de todos los documentos del colaborador.
3. Enviar los documentos de Normatividad vía Jotform para la firma correspondiente.

## Onboarding — Footprint

1. Enviar el correo para que el colaborador se registre en Jotform.
2. Con los datos del registro, darlo de alta en Holded.
3. Enviar toda la documentación requerida en la normatividad vía Jotform para firma.
4. Subir los documentos ya firmados al espacio del colaborador en Holded.
5. Si el colaborador necesita tarjeta corporativa:
   - Realizar el proceso de emisión de la tarjeta.
   - Enviarle los pasos para su activación.

## Offboarding

⚠️ **Vacío por llenar** — el documento de responsabilidades no detalla un proceso de offboarding explícito para ninguna de las tres empresas (BAE, Footprint, eWorks). No se documentan pasos de baja de colaboradores (cierre de accesos, retiro de tarjetas, cierre de usuario en Holded, etc.). Hay que definir y documentar este proceso.

---

**Nota:** Este proceso es manual por ahora. El asistente puede guiarte paso a paso si le preguntas, pero no ejecuta ninguna acción de este módulo automáticamente.
